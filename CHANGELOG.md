# Changelog

## 0.1.0

First release.

- Timed, system-wide website blocking through `/etc/hosts`
- Immutable hosts file, self-repairing daemon and watchdog timer
- Countdown on the monotonic boot clock; survives reboots and clock changes
- Nine ready-made lists, custom lists and an allowlist
- Guided menu and one-line commands
- DNS-over-HTTPS switched off in common browsers during a block
